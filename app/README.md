# app/

Planned interactive demo: predicted future scenes of the object-centric, BEV and
latent-BEV world models shown side by side with the ground truth, with the ego action
selectable to show how the forecasts react to it.

Until it exists, the visual demo is the BEV notebook
(`notebooks/BEVFusion_Encoder.ipynb`): camera and BEV views with obstacles and
trajectories, plus an animated drive through a scene.
